# AI 美发沙龙管家 · 使用说明

## 一、这是什么

一个接入 DSH（deepseek-harness-java）的美发沙龙 AI 助手。前端是运营工作台，右侧 AI 助手可以直接帮你查价目、查发型师、预约下单、查预约、看运营数据——全程自然语言，无需点菜单。

## 二、启动步骤

1. **启动业务应用**（端口 18110）：
   ```bash
   SERVER_PORT=18110 java -jar p-app/target/p-app-1.0.0-SNAPSHOT.jar
   ```
2. **确认 DSH 已运行**（端口 8090）且 `salon-copilot` 插件已安装激活：
   ```bash
   curl -s http://127.0.0.1:8090/api/harness/plugins | grep salon-copilot
   ```
3. **打开工作台**：浏览器访问 http://127.0.0.1:18110

## 三、AI 能做什么（试试这些话）

| 你说 | AI 做 |
|------|-------|
| 「烫发多少钱？需要多长时间？」 | 调 `service_list`，列出项目价格与时长 |
| 「有哪些发型师？擅长什么？」 | 调 `stylist_list`，返回职级、擅长与评分 |
| 「帮我预约精剪造型，周四 15:00，吴先生 13800007777」 | 调 `book`，**先复述要素请你确认**，确认后预约并给单号 |
| 「查一下预约 H1002 的状态」 | 调 `order_info`，返回详情与状态 |
| 「今天整体运营情况怎么样？」 | 调 `stats`，订单/营收/建议一览 |

## 四、业务规则

- **预约确认制**：AI 预约前必须复述项目、价格、发型师、到店时间，经你确认后才真正下单。
- **编号规则**：预约单号 `H1001+`。
- **默认发型师**：预约未指定发型师时默认分配总监阿凯（S01）。
- **优惠规则**：烫发 + 染发同做享 8 折；会员剪发 9 折。
- **护理提醒**：染发前建议做过敏测试；染后 48 小时内不洗头保持护色。

## 五、常见问题

**Q：AI 一直显示「…」不动？**
AI 可能在调用 `ask_user_question` 等待你补充信息（如缺少到店时间）。把信息补齐重发即可；若仍卡住，等待约 1-2 分钟或重启 DSH 后重试。

**Q：插件激活失败 / 调用了旧工具？**
先卸载再重装：`POST /api/harness/plugins/salon-copilot/uninstall`，删除 `~/.dsh/standalone/plugins/salon-copilot.jar` 残留，重新 install + activate，并重启 DSH 以清空会话缓存。

**Q：换端口怎么改？**
应用端口：`SERVER_PORT=xxx` 环境变量；插件连应用端口：环境变量 `SALON_APP_BASE_URL`（默认 `http://127.0.0.1:18110`）。
